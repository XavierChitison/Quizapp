## 🧠 How It Works

The quiz stores questions and possible answers using JavaScript.

When the user selects an answer, JavaScript determines whether the selected answer is correct, updates the player's score, and moves the game to the next question.

The webpage is updated dynamically through the DOM instead of requiring the page to reload after every question.

At the end of the quiz, the player's final score is displayed and the user can restart the game.

## ▶️ Running the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start the quiz and select your answers.
5. Complete all questions to see your final score.

No additional installation or dependencies are required.
